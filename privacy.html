Privacy Policy

Effective 13 November 2026

StitchKit is a private Windows desktop app. It is built and used by one seller to run their own shop of printable cross stitch patterns. It is not offered to anyone else, it has no server, and it has no user accounts. This policy explains what the app does with information from the services it connects to.

Services it connects to

StitchKit connects only to the seller's own accounts, through each service's official API, after the seller signs in and approves access with OAuth 2.0:

  • Etsy: to read the seller's shop details and sections, create draft digital-download listings, and upload or update those listings' images, files, video, wording and price.
  • Pinterest: to list the seller's own boards and create pins on them, each with an image, title, description, alt text and a link to the matching listing in the seller's shop.

What information it uses

  • The seller's own account and shop details that each service returns (such as the shop name, sections and boards), so the seller can choose where things go.
  • The seller's own content: pattern files, images, listing text and the posts the seller plans.
  • Sign-in tokens from each service, so the app can act for the seller.

StitchKit does not read other people's pins, profiles, listings or messages. It does not follow, like or comment, does not collect analytics, and does not scrape websites.

Where information is kept

  • Everything stays on the seller's own computer. Sign-in tokens and API secrets are encrypted with Windows' data protection, and are never included in the app's backups or export files.
  • Information is sent only to the service it belongs to, through that service's API (for example, a pin is sent only to Pinterest).
  • Nothing is sold, shared with third parties, or used for advertising.

Buyers' information

When the seller imports their own Etsy order reports, StitchKit keeps only what's needed for sales totals (items, dates, prices and listing numbers). It never stores buyers' names, addresses or contact details.

The sign-in return page

This website hosts a page that services return to after the seller approves access. It only passes a one-time code to the app on the same computer and stores nothing. The site is hosted by GitHub Pages, which may keep standard server logs under GitHub's privacy statement. The site sets no cookies and has no tracking.

Keeping and deleting information

  • Disconnecting a service in StitchKit's settings deletes its sign-in tokens from the computer.
  • Access can also be removed at any time from each service's own settings (Etsy: Account settings → Apps; Pinterest: Settings → Security and logins → Apps).
  • Content the app has posted stays on the service until the seller deletes it there.

Children

StitchKit is not directed at children and doesn't knowingly handle children's information.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
