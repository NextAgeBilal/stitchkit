# StitchKit

The public pages for StitchKit, a private Windows desktop app that prepares and lists digital cross stitch patterns in one seller's own shop.

- `index.html`: what the app does and how it handles data. https://nextagebilal.github.io/stitchkit/
- `callback.html`: the OAuth 2.0 return page. It passes the one-time sign-in code back to the app on the same computer (127.0.0.1) and keeps nothing.

The app's code is not in this repository.
